# Speckle Pattern (Speckle Pattern Simulation and Noise Reduction using MATLAB) 

## Project Overview

This project was developed as part of my **M.Sc. Physics dissertation**. It focuses on the simulation of **speckle noise** in digital images and its reduction using MATLAB-based image processing techniques. A graphical user interface (GUI) was developed to make the complete workflow interactive and user-friendly.

---

## Objectives

- Simulate speckle noise in digital images.
- Analyze the effect of speckle noise on image quality.
- Reduce noise using image filtering techniques.
- Develop an interactive MATLAB GUI.
- Compare original, noisy, and filtered images.

---

## Features

- Upload an image
- Generate Speckle Noise
- Adjust Noise Strength
- Apply Noise Reduction Filter
- Display Original, Noisy, and Filtered Images
- Save Processed Images
- User-friendly MATLAB GUI
